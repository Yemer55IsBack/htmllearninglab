Learn HTML Today

The interactive, hands-on way to write your first lines of code. Read the short lessons below and click TRY IT to experiment in the Live Editor!

1. Tags & Elements

HTML uses tags to label pieces of content. Most tags come in pairs: an opening tag and a closing tag. The closing tag has a forward slash /. The content you want to display goes right in the middle! 

<button>Click Me!</button>
<p>This is a paragraph inside tags.</p>

2. Headings & Paragraphs

Headings make text big and bold, perfect for titles. There are 6 levels, from <h1> (biggest) to <h6> (smallest). Regular text is wrapped in a <p> (paragraph) tag. 

<h1>Main Title Here</h1>
<h2>A Subheading</h2>
<p>This is just a normal paragraph of text on the web page.</p>

3. Formatting Text

You can style words directly in HTML! Use <strong> for bold text, and <em> for italics. The <br> tag forces a line break—it's a special "empty" tag that doesn't need to be closed. 

<p>This sentence contains <strong>important bold words</strong>.</p>
<p>This has some <em>emphasized italics</em>.</p>
<p>First line.<br>Second line pushed down.</p>

4. Links & Images

Tags can have attributes to provide extra info. Links use the <a> (anchor) tag with an href attribute pointing to a URL. Images use the <img> tag with a src attribute for the image file. 

<!-- Creating a clickable link -->
<a href="https://www.google.com" target="_blank">Go to Google</a>

<!-- Displaying an image -->
<img src="https://images.unsplash.com/photo-1543466835-00a7907e9de1?w=300" alt="Puppy">

5. Making Lists

Create unordered (bulleted) lists with <ul> or ordered (numbered) lists with <ol>. Inside, wrap every list item with an <li> tag. 

<h2>My Grocery List</h2>
<ul>
  <li>Apples</li>
  <li>Bananas</li>
</ul>
